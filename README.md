# 大学生央国企求职导航
> 专为应届毕业生整理的官方求职平台快捷导航，一键直达，省去到处找官网的麻烦。

## ✨ 项目说明
很多应届生找央国企、事业单位招聘官网时容易搜到第三方广告网站、钓鱼链接。
这个页面把主流官方求职入口汇总到一起，全部为官方原链接，点击直接新标签页打开。

## ⚠️ 重要提醒
⚠️ 凡是要求先交培训费、押金、体检费、安置费的招聘，一律高度警惕，谨防求职诈骗！

## 📍 在线访问地址
👉 https://dxiangwiki.github.io/job-nav/

## 📋 包含平台清单
- 国家大学生就业服务平台
- 国资委央企招聘平台、国聘网
- 中国公共招聘网、中国就业网、中国国家人才网
- 国家烟草、国家电网、南方电网
- 中国铁路人才网、中石化、中石油、中国海油
- 中国移动、中国电信、中国联通
- 军队人才网、应届生求职网、银行招聘网等

## 💡 使用方法
1. 打开上面的在线链接
2. 勾选【显示网址】可以查看原始官网地址，方便核对
3. 点击条目，在新标签页进入对应招聘平台

## 📌 补充
- 本项目仅做链接聚合，**不提供简历内推、付费辅导、求职培训服务**
- 链接均为公开官方地址，如遇到官网改版失效，欢迎提 Issue 反馈更新
